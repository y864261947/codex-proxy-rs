## 不变量

- 旧 Key 权限范围与空池拒绝语义保持；流式交付后的请求不得换号重放。
- 数据库变更新增迁移，原有迁移 checksum 不变。
- 运行占用与完成日志分开；一次逻辑请求的多次上游尝试不能增加下游并发。
- 测试与探针不混入客户业务统计，但仍受真实来源容量约束。
- 生产服务和生产数据不作为开发测试环境。

## 批次 1 的实际行为

- `GET /api/admin/dashboard/realtime` 复用管理端鉴权与 `no-store`，直接读取共享内存计数；每 5 秒轮询不增加数据库查询。
- 入口 RPM 统计四个现有业务 POST 端点和 WebSocket 文本创建尝试，包括未通过认证/解码的请求；后台查询、模型列表、连接升级、空闲连接及内部账号探针排除。采用当前秒及之前 59 秒的固定桶，精度 1 秒。
- 实时并发是进入 Core 的逻辑执行数，拆分为准备中和执行中。重试不重复累计；失败、正常终态、取消收敛或会话丢弃释放计数。短暂的认证/解码阶段不计入执行并发。
- 指标仅覆盖当前单进程；重启清零，启动不足 60 秒和采样失败在 UI 明示。尚未引入队列和异步视频任务，不显示虚构的零值。
- 首页与监控中心复用实时负载卡片；监控中心同时展示既有号池容量和健康趋势（这些完成统计保持原有 30 秒刷新）。
- 自建号池下提供账号、号池分组两个入口；旧 `/accounts`、`/account-groups` 地址继续跳转，具名路由保留。
- 本批次未修改数据库迁移、下游 Key 权限和生产部署。
